## DESIGN DIRECTION

### Aesthetic DNA
The visual identity is built around the "Entre dos orillas" (Between Two Shores) concept — a palette that shifts between two emotional registers: the warmth of Paraguay and the cool distance of Abu Dhabi / diaspora. Combined with:
- **Archival/editorial aesthetic** — Monospace labels, grid systems, catalog-style numbering, file-system metaphors
- **Sound engineering motifs** — Waveforms, mixing console faders, volume knobs, frequency spectrums as decorative and structural elements
- **Contemporary music notation** — Abstract staff lines, rhythmic patterns as graphic textures
- **Halftone/collage textures** — Photographic grain, halftone dots for image treatments
- **Cassette tape / vinyl aesthetic** — Nostalgic music formats as visual references
- **Dual-register color system** — Warm tones for Paraguayan/roots content, cool tones for Abu Dhabi/diaspora content. The palette itself tells the story of displacement.

### Color Palette — "Entre dos orillas"

The palette has TWO emotional registers plus connective neutrals. Use them semantically: warm for Paraguayan roots content (EP, compositions, cultural work), cool for Abu Dhabi/diaspora content (post-production, studio work, professional services), and connective for shared/neutral spaces (navigation, typography, backgrounds).

```css
:root {
  /* ── Paraguay register — warm ── */
  --color-burnt-amber: #C17B2F;    /* Primary warm tone. Paraguayan roots content. */
  --color-gold-ochre: #D4922B;     /* Golden hour. Fields, warmth, memory. */
  --color-warm-gold: #E8B86D;      /* Light fills, overlays, soft highlights. */
  --color-pale-dust: #E8D5C0;      /* Warm backgrounds, paper tones, negative space. */
  --color-terracotta: #A0522D;     /* Accent. Earth, worn surfaces, depth. */

  /* ── Abu Dhabi register — cool ── */
  --color-deep-navy: #1B2A3B;      /* Shadows, depth, night register. */
  --color-cobalt: #3D5FAD;         /* Ana's signature color. The figure in the drawing. */
  --color-mid-blue: #6B8FC4;       /* Transitions. Between the two registers. */
  --color-silver-haze: #8B9EAE;    /* Migration, in-between states, cool light. */
  --color-pale-haze: #B8C4CC;      /* Negative space in cool-register content. */

  /* ── Connective — shared across both registers ── */
  --color-deep-sage: #2D4A3E;      /* Something still alive, still growing. Use rarely. */
  --color-dark-shadow: #4A3728;    /* Deep shadows, candlelight contrast, intimacy. */
  --color-off-white: #F5F0EB;      /* Clean backgrounds. Editorial moments. Primary bg. */
  --color-charcoal: #2C2C2C;       /* Typography. Never use pure black. */
}
```

**Usage rules:**
- Default background: `--color-off-white` (#F5F0EB) for light sections, `--color-deep-navy` (#1B2A3B) for dark sections.
- Primary text: `--color-charcoal` (#2C2C2C) on light backgrounds. Never pure #000000.
- Primary accent: `--color-cobalt` (#3D5FAD) — Ana's signature. Use for interactive elements, links, active states.
- Warm accent: `--color-burnt-amber` (#C17B2F) — For EP/compositions sections and Paraguayan cultural content.
- Section transitions can shift the palette register: scrolling from a warm section (EP) into a cool section (post-production work) mirrors the "two shores" concept.
- `--color-mid-blue` (#6B8FC4) is the bridge color — use it in transitions between registers.

### Typography
- **Display/Headlines**: Bold, uppercase, geometric sans-serif (Monument Extended, PP Neue Montreal, Clash Display, or Space Grotesk). Used for section titles, project names, hero text.
- **Body**: Clean sans-serif (Inter, Satoshi, or General Sans). Used for descriptions, paragraphs.
- **Monospace**: JetBrains Mono, IBM Plex Mono, or Space Mono. Used for: dates, project codes, category labels, technical specs, role descriptions. This is key to the archival aesthetic.
